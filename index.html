What we do

Doron AI Studios produces AI-generated cinematic video content and publishes it across a growing set of brand personas and social media accounts. Our current work spans multiple video series and account personas, with our first TikTok persona, LL eMMa, now live as we expand this side of the operation.

Our publishing tool

To keep production and distribution consistent as we scale across multiple accounts and platforms, we built a publishing pipeline that connects our content production process directly to the social platforms we operate on: TikTok, Instagram, Facebook, and YouTube.

The tool handles the operational side of publishing — uploading finished video content to each platform's own API, applying the right formatting and metadata for each platform, and keeping our multi-persona output moving without manual per-account uploads. It is used solely to publish content we authored to accounts we own and operate; it is not offered to external users or clients.

Platforms we publish to

  • TikTok — via the Content Posting API
  • Instagram — via the Instagram Graph API
  • Facebook — via the Meta Graph API
  • YouTube — via the YouTube Data API
